# Forkable GPU Memory for Replayable Agent Execution (v0.1)

Branch-aware copy-on-write of attention KV-cache pages on NVIDIA H100, using the CUDA
Virtual Memory Management (VMM) driver API so forking happens at the **GPU MMU**
(cuMemCreate / cuMemMap / cuMemUnmap / cuMemRetainAllocationHandle) — not os.fork, not a
pure-Python tensor copy.

See `WRITEUP.md` for results, `LIMITATIONS.md` for caveats, `CITATIONS.md` for related
work, `prototype_status.md` for what works / is mocked / is broken.

## Layout
```
src/    vmm_pool.py            CUDA VMM physical-page + VA manager (the mechanism)
        kv_branch_manager.py   Snapshot / Fork / CoW / refcount / divergence detector
        baseline_fullclone.py  Full-clone baseline (mimics naive vLLM cloning)
        replay.py              Record/replay with controlled nondeterminism
        explog.py              experiment_log.jsonl writer
        test_primitives.py     Priority-1 unit test (snapshot/fork/cow/refcount/diverge)
        test_replay.py         Priority-2 unit test (replay + divergence)
bench/  bench_metric1_fork_latency.py
        bench_metric2_bytes_written.py
        bench_metric2b_divergence.py
        bench_metric3_attn_overhead.py
        bench_metric4_capacity.py
        bench_metric5_e2e_trajectories.py   (reads m5_config.json + real SWE-bench parquet)
        bench_crossdomain_granularity.py
        make_figures.py
data/   *.csv raw outputs, swe_verified_test.parquet (real SWE-bench-Verified)
figures/ *.png  (regenerated by make_figures.py)
```

## Reproduce everything
```bash
source .venv/bin/activate    # or use .venv/bin/python
python src/test_primitives.py            # Priority-1 correctness
python src/test_replay.py                # Priority-2 correctness
python bench/bench_metric1_fork_latency.py
python bench/bench_metric2_bytes_written.py
python bench/bench_metric2b_divergence.py
python bench/bench_metric3_attn_overhead.py
python bench/bench_metric4_capacity.py        # ~minutes (fills 94 GiB for clone OOM)
python bench/bench_metric5_e2e_trajectories.py
python bench/bench_crossdomain_granularity.py
python bench/make_figures.py                  # writes figures/*.png
```
Each run appends to `experiment_log.jsonl` (timestamp + git hash + params + result).

## Notes
- Run metric4 / metric5 with no other GPU process (they allocate most of HBM).
- `cuda.cuda` emits a deprecation FutureWarning; harmless for v0.1.
